# Forge-app

Det här är en Forge-app. Läs skillen `forge-new-app` / `forge-edit-app` innan du ändrar något.

- `forge.json` är manifestet (namn, typ, startfil, behörigheter).
- Använd `forge.css` för utseendet så att appen matchar resten av systemet.
- Rör inga filer utanför den här katalogen.
- Starta/testa: `forge run <app>`.
